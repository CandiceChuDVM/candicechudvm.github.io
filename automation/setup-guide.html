CV Sync Setup Guide

Upload your CV to Google Drive → Claude extracts changes → Slack asks you to approve → GitHub auto-updates your website.

Step-by-step setup

1
Copy the automation folder to your GitHub repo

The automation/ folder from this project contains all scripts. Copy it to the root of your candicechudvm.github.io repo. Also copy the two workflow files into .github/workflows/:

candicechudvm.github.io/
├── .github/
│   └── workflows/
│       ├── cv-sync.yml          ← from automation/workflows/
│       └── apply-change.yml     ← from automation/workflows/
├── automation/
│   ├── scripts/
│   │   ├── download_from_drive.py
│   │   ├── parse_cv.py
│   │   ├── diff_cv.py
│   │   ├── notify_slack.py
│   │   ├── apply_change.py
│   │   └── slack_confirm.py
│   ├── data/
│   │   └── site_data.json
│   └── cloudflare-worker.js
└── ... (your existing website files)
⚠️ Important: Do NOT overwrite any existing index.html or other website files. Place only the automation/ folder and .github/workflows/ files.
2
Create a Google Cloud Service Account

This lets GitHub Actions download your CV from Drive.

  1. Go to console.cloud.google.com → create a new project
  2. Enable the Google Drive API
  3. Go to IAM & Admin → Service Accounts → Create service account
  4. Download the JSON key file
  5. In Google Drive, share your CV folder with the service account email (Viewer role)

Copy the entire contents of the JSON key file — you'll use it as the GDRIVE_SERVICE_ACCOUNT_JSON secret below.

3
Add GitHub Actions secrets

Go to your GitHub repo → Settings → Secrets and variables → Actions → New repository secret. Add each of these:

Secret nameValue
ANTHROPIC_API_KEYYour Claude API key from console.anthropic.com
GDRIVE_SERVICE_ACCOUNT_JSONFull JSON content of the service account key file
SLACK_BOT_TOKENxoxb-... token from your Slack App (see step 4)
SLACK_CHANNEL#website-updates
SLACK_SIGNING_SECRETFrom Slack App → Basic Information (used by Cloudflare Worker)
GITHUB_TOKENAuto-provided by Actions — no setup needed
4
Create a Slack App

Go to api.slack.com/apps → Create New App → From scratch. Name it "Chu Lab CV Bot".

  1. OAuth & Permissions → add Bot Token Scopes: chat:write, chat:write.public
  2. Install to Workspace → copy the xoxb-... Bot Token
  3. Basic Information → copy the Signing Secret
  4. After deploying the Cloudflare Worker (step 5), come back here and enable Interactivity & Shortcuts → paste your Worker URL
5
Deploy the Cloudflare Worker

The Worker receives Slack button clicks and dispatches GitHub Actions.

  1. Go to workers.cloudflare.com → Create Worker
  2. Paste the contents of automation/cloudflare-worker.js
  3. Go to Settings → Variables → add secrets:
    SLACK_SIGNING_SECRET, GITHUB_TOKEN, GITHUB_OWNER (candicechudvm), GITHUB_REPO (candicechudvm.github.io)
  4. Deploy and copy the Worker URL (e.g. https://chu-lab-cv.workers.dev)
  5. Paste this URL into your Slack App's Interactivity → Request URL
6
Install the Google Apps Script

This watches your Drive folder and triggers the pipeline.

  1. Go to script.google.com → New Project
  2. Paste the contents of automation/google-apps-script.js
  3. Fill in DRIVE_FOLDER_ID, CV_FILENAME, and GITHUB_TOKEN in the CONFIG block
  4. Run installTrigger() once — authorize when prompted
  5. Run testManualTrigger() to verify everything works end-to-end
💡 Tip: The trigger checks every 30 minutes. You can change CHECK_INTERVAL_MINUTES in the CONFIG. The minimum is 1 minute on the free Apps Script plan.
7
Test the full pipeline

Upload a new version of your CV to your Google Drive folder, then either wait for the trigger or run testManualTrigger() in the Apps Script editor. Within a few minutes you should see approval messages appear in #website-updates on Slack.

✅ What to expect: One Slack message per new item (publication, talk, etc.). Click Approve on each item you want on the website. The bot will commit the change and reply with a confirmation. Your site updates within ~1 minute via GitHub Pages.
