Dashboards

Cloudflare Web Analytics Page views, referrers, visitor countries, device and browser mix. Free, cookie-free, no consent banner. Google Search Console What people searched before clicking, which pages rank, and any indexing problems. Add both candicechudvm.com and the sitemap. Bing Webmaster Tools The same for Bing — which also feeds several AI answer engines. GitHub Actions runs Every deploy, with the build and validation log. A red run means the live site is still the previous version. GitHub Pages settings Custom domain and HTTPS status.

Turning it on

  1. Pick a provider in _data/site.json → analytics.provider and paste its id.
  2. Rebuild and deploy: node _build/build.mjs, then commit and push.
  3. Open the site in a private window, then confirm the visit appears in the dashboard.
  4. In Search Console, submit https://candicechudvm.com/sitemap.xml once. It re-reads it automatically after that.
  5. Optional: paste a shared dashboard URL into _data/backstage.json → embed.url to see the numbers on this page.

Cloudflare, Plausible, Umami and GoatCounter are all cookie-free and collect no personal data, so no consent banner is required. GA4 does set cookies — if you choose it, a privacy notice becomes necessary.
